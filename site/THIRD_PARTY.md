# Third-party files

The three fonts below are self-hosted in `fonts/`. Each is the latin, normal-style,
variable-weight woff2 file from the Fontsource package of the same name. Each is
licensed under the SIL Open Font License, Version 1.1.

| Font | File | Package | Licence |
|---|---|---|---|
| Fraunces Variable | `fonts/fraunces-latin-wght-normal.woff2` | `@fontsource-variable/fraunces` | SIL OFL 1.1 |
| Public Sans Variable | `fonts/public-sans-latin-wght-normal.woff2` | `@fontsource-variable/public-sans` | SIL OFL 1.1 |
| JetBrains Mono Variable | `fonts/jetbrains-mono-latin-wght-normal.woff2` | `@fontsource-variable/jetbrains-mono` | SIL OFL 1.1 |

The full licence text is included in each npm package. No other third-party code,
font, stylesheet or network asset is used by the site.
