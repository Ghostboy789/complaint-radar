# Third-party files

The two fonts below are self-hosted in `fonts/`. Each is the latin, normal-style,
variable-weight woff2 file from the Fontsource package of the same name. Each is
licensed under the SIL Open Font License, Version 1.1.

| Font | File | Package | Licence |
|---|---|---|---|
| Unbounded Variable | `fonts/unbounded-latin-wght-normal.woff2` | `@fontsource-variable/unbounded` | SIL OFL 1.1 |
| Inter Tight Variable | `fonts/inter-tight-latin-wght-normal.woff2` | `@fontsource-variable/inter-tight` | SIL OFL 1.1 |

The full licence text is included in each npm package. No other third-party code,
font, stylesheet or network asset is used by the site.
